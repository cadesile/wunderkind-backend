## Summary
This SKILL.md defines a design-intelligence skill for AI coding agents doing UI/UX work — spanning 67 styles, 96 color palettes, 57 font pairings, and 25 chart types across 13 tech stacks (React, Next.js, Vue, Svelte, SwiftUI, React Native, Flutter, Tailwind, shadcn/ui). An agent should read it whenever a task involves designing, building, reviewing, or fixing UI/UX (pages, components, dashboards, mobile apps) to get prioritized guidelines on accessibility, touch/interaction, performance, layout, typography, color, animation, style selection, and charts.

Practically, it instructs the agent to run a Python CLI (`scripts/search.py`) with a `--design-system` flag to generate a full design system (pattern, style, colors, typography, effects, anti-patterns) from a short product/style/industry query, and optionally `--persist` to save it as a MASTER.md plus per-page override files for reuse across sessions. It also covers Python prerequisite checks/install commands per OS before running the tool.
