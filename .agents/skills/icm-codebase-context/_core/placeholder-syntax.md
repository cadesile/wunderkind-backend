# Placeholder syntax

Used only in `setup/questionnaire.md` and `shared/stack.md` — the two files
that get filled in once, during onboarding (see stage `01_overview` and the
questionnaire itself).

- A placeholder is written `{{NAME}}` — uppercase, underscores, no spaces.
- Replace every instance of a placeholder with the answer you collected for
  it. If the same placeholder appears in more than one file, replace all of
  them consistently.
- After replacing, scan every file you touched for any remaining `{{`. If
  any remain, ask the human for the missing information — do not guess a
  value and do not leave a placeholder in a file you present as finished.
- Onboarding (or stage `01_overview`) is complete only when zero
  placeholders remain in the files it's responsible for.
